# Homebrew Tap

This repository is the Homebrew tap for Sampo's CLI tools.

## Add the tap

```bash
brew tap sukkola/tap
```

## Install tools from this tap

```bash
brew install sukkola/tap/jqpp
brew install sukkola/tap/openapiv3-filter
```

## Available formulas

- `jqpp` - Interactive jq TUI with smart completions and LSP integration.
- `openapiv3-filter` - Filters OpenAPI v3 documents by path, method, tag, and security.
